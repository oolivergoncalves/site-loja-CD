Este projeto consiste em uma loja virtual de CDs, desenvolvida como parte de uma atividade acadêmica. 
O site foi criado para aplicar conhecimentos de desenvolvimento web e está organizado nas seguintes páginas:

Início: apresentação da loja;
Catálogo: exibição dos CDs disponíveis;
Sobre: informações sobre a loja e o projeto;
Contato: canal para comunicação com a loja.
